# Face-to-Face Live Translator

A dual-screen, dual-microphone live translation device built on a Raspberry Pi.

Each speaker uses their own push-to-talk microphone. Speech is transcribed and
translated in real time and displayed side-by-side on mirrored screens.

## Tech Stack
- Python
- Raspberry Pi
- Google Speech-to-Text
- Google Translate
- Tkinter
- sounddevice / ALSA

## Status
Working prototype.
